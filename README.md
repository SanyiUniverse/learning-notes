# 学习资料 · Learning notes

这里按主题整理学习资料。每个主题放在自己的文件夹里，手册、演示、图片和其他补充材料放在一起。

## 排序算法：从零开始

这份学习包面向没有算法基础的读者，从数字的大小、位置、比较和移动讲起，再逐步学习排序方法。

**[下载完整学习包](https://raw.githubusercontent.com/SanyiUniverse/learning-notes/main/排序算法/排序算法学习包.zip)**

1. 下载后解压，打开“排序算法学习包”文件夹。
2. 双击 **`00_从这里开始.html`**，用 Safari、Chrome 或 Edge 打开。
3. 按“下一小节”学习；读到需要补充的地方，再打开对应动画或参考册。

总手册有 37 个入门小节、80 个完整学习条目和 18 项基础补充。80 是学习条目数，包含算法、重要变体、算法家族和辅助技术，不能理解成 80 个独立发明；覆盖范围和未展开的内容在手册中说明。

插入、选择、冒泡、归并、Lomuto 快速和稳定计数排序有六种离线长条动画，可以逐步查看、回到上一动作、慢播和暂停。所有 80 个条目都有具体步骤、数字例子、效率条件和参考来源，必要处配有原创步骤图。

正文、图和动画支持离线使用，不需要安装软件或注册账号。请把学习包的四个文件放在同一文件夹里，保证它们之间的跳转有效。外部参考来源需要联网。

完整参考册也可以单独查看：

- [中文版 PDF](排序算法/排序算法学习手册_中文版.pdf)
- [English PDF](排序算法/Sorting_Algorithms_Learning_Manual_English.pdf)

## English

**[Download the complete sorting package](https://raw.githubusercontent.com/SanyiUniverse/learning-notes/main/排序算法/排序算法学习包.zip).**

Extract the ZIP and open `00_从这里开始.html` in your browser. Select **English** at the top, then follow **Next section**. Open a matching animation or reference only when you need it. Keep all four package files together so their local links work.

The manual starts with simple comparisons and movements. It includes 37 guided sections, 80 full learning entries, 18 foundation sections, six offline bar animations, and complete Chinese and English references. Entries include variants, families, and supporting techniques as well as algorithms. They do not represent 80 independent inventions. The manual explains its coverage and limits.

Lessons, diagrams, and animations work offline without installation or an account. External reference links need internet access.

## 以后怎样添加资料

新主题新建一个文件夹，例如“英语学习”或“数学笔记”；同一主题的资料继续放在对应文件夹中。需要多个文件的主题，优先提供一个“从这里开始”的总入口，让读者知道先看什么、需要时再打开什么。
